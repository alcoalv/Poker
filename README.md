# POKER TABLE

브라우저에서 바로 실행하는 카드게임입니다. 텍사스 홀덤과 세븐 카드 스터드, 2~6명 테이블(본인 + AI), 두 모드의 안내형 한 판 튜토리얼 및 족보 가이드를 제공합니다. 실제 돈이나 계정 연동은 없습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 외부 패키지 설치나 빌드 과정은 필요하지 않습니다. Google Fonts에 접근할 수 없으면 기기 기본 글꼴을 사용합니다.

## GitHub Pages 게시

1. 이 폴더의 `index.html`, `style.css`, `poker.js`, `app.js`를 GitHub 저장소의 루트에 올립니다. (`README.md`와 `tests.js`는 선택 사항입니다.)
2. 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 브랜치와 `/ (root)`를 선택합니다.
3. 표시된 Pages 주소로 게임을 엽니다.

## 규칙과 조작

- **홀덤:** 10/20 블라인드, 개인 카드 2장, 플랍 3장 → 턴 1장 → 리버 1장. 버튼은 매 판 한 칸 이동합니다.
- **세븐 스터드:** 5 앤티, 10 브링인, 처음 2장 비공개 + 1장 공개, 이후 3장 공개, 마지막 1장 비공개. 첫 거리의 낮은 도어 카드가 브링인하며, 이후 공개 패가 높은 사람부터 행동합니다.
- 두 모드 모두 **선택형 베팅**입니다. 초반의 기본 단위는 20, 후반은 40입니다. `BET / RAISE ×1·×2·×4`는 해당 단위(또는 직전 레이즈의 최소 증액)의 1·2·4배를 베팅하고, 버튼에는 실행 후 **총 베팅액**이 표시됩니다. `ALL-IN`은 남은 칩 전부를 겁니다. 칩이 부족하면 콜도 올인으로 처리합니다. 짧은 올인은 이미 행동한 플레이어의 재레이즈 권한을 새로 열지 않습니다.
- 승자 배너와 좌석의 **WINNER** 표시로 팟 수령자를 보여줍니다. 복수 승자나 서로 다른 올인 금액은 메인 팟과 사이드 팟을 분리해 정산합니다.
- **Easy / Normal / Hard**는 AI가 참고하는 패의 강도, 보이는 카드, 추정 승률과 베팅 판단이 달라집니다. 완전한 게임 이론 솔버는 아닙니다.
- 우측 상단 **? HAND GUIDE**에서 열 가지 족보, 동일 족보 비교, A 예외, 무늬와 무승부 규칙을 확인합니다. ESC로 플레이를 일시정지할 수 있습니다.

## 누적 상금 · Spoon 티어

한 판에서 플레이어가 **실제로 받은 팟 칩**을 누적 상금으로 계산합니다. 상대가 맞추지 않아 돌려받은 칩은 상금에서 제외합니다. 패배하면 이번 판 상금은 0이며, 기존 상금이나 티어는 차감되지 않습니다. 튜토리얼에는 상금을 지급하지 않습니다. 시작 칩 1,000개는 매 새 게임에 다시 지급하며, 상금은 별도의 누적 기록입니다.

| 티어 | 필요한 누적 상금 |
|---|---:|
| No Tier | 0 |
| Silver Spoon | 1,000 |
| Gold Spoon | 5,000 |
| Platinum Spoon | 15,000 |
| Challenger Spoon | 40,000 |
| Legendary Spoon | 100,000 |

첫 화면과 테이블의 진행 막대에서 현재 티어와 다음 목표를 볼 수 있습니다. **TIERS** 버튼은 전체 기준과 플레이 기록을 보여줍니다. 티어·누적 상금·획득 판수는 해당 브라우저의 `localStorage`에 자동 저장됩니다. 저장소를 차단하거나 브라우저 데이터를 지우면 기록을 유지할 수 없으며, 기기 간 동기화는 지원하지 않습니다.

## 검사

Node.js가 있으면 `node tests.js`로 족보 순위·키커·A-5 스트레이트·무늬 동률, 두 게임의 완전한 한 판과 칩 보존, 상금 지급·티어·저장 복원, 2배·4배·올인과 사이드 팟을 검사할 수 있습니다.
